# planning ディレクトリ概要

マイルストーンや実装計画を体系的に整理し、`task_progress/` で扱う日次タスクへ落とし込むためのハブです。下記3ファイルを常に同期させてください。

1. `roadmap.md` — 長期/中期フェーズの方針と成功基準をまとめる。
2. `milestones.md` — 直近で着手すべきマイルストーンを詳細化し、依存関係と完了条件を明記する。
3. `backlog.md` — 細分化した実装アイデアや調査タスクを列挙し、`task_progress/current.md` へ移す前段階として管理する。

更新時の流れ:
- 新しい戦略や制約が生じたら `roadmap.md` に追記し、関連するマイルストーンを `milestones.md` に追加。
- マイルストーンを実作業へ分解したら `backlog.md` にサブタスクとして記入し、着手時に `task_progress/current.md` へコピーしてステータス管理する。
- 完了したマイルストーンは `milestones.md` の状態を更新し、得られた知見は `roadmap.md` に反映する。
