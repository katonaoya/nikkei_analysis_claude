# 終値モデル 精度強化優先計画（2025-10-26改訂）

## 目的
- Precision 60%超を安定維持しつつ、ヒット率とネットリターンを同時改善するための強化施策を優先度順に整理する。
- 当面 3 か月間の実装ロードマップの指針として活用し、週次レビューで進捗と効果を評価する。

## 優先順位一覧
| 優先度 | 施策カテゴリ | 期待効果 (Precision) | 主なゴール | 依存関係 / 前提 |
| --- | --- | --- | --- | --- |
| 1 | データ多様化と特徴量拡張 | ★★★ (+2〜4pt想定) | 代替データとマーケット指標でシグナル説明力を底上げ | J-Quantsベースデータが安定取得できること |
| 2 | モデリング刷新（アンサンブル/深層学習） | ★★★ (+2〜3pt) | LightGBM単体から脱却し、Precision>65%を狙う | 施策1の新特徴量が利用可能であること |
| 3 | 確率キャリブレーション & リスク管理 | ★★☆ (+1〜2pt) | 確率キャリブレーション自動化とリスク制御 | 施策2の新モデル or 既存モデル出力にアクセス可能 |
| 4 | マルチタスク化（リターン/出来高予測） | ★★☆ (+1pt、実効リターン向上) | 翌日リターン分布や出来高を同時推定し、シグナル品質を精緻化 | GPU環境 or 並列計算基盤、施策1で拡張した特徴量 |
| 5 | モニタリング自動化 & ドリフト検知 | ★☆☆ (安定維持) | 週次モニタリングと自動アラート | 既存レポート生成パイプライン |
| 6 | 意思決定レイヤ最適化（ポートフォリオ/サイズ） | ★☆☆ (Precision維持、リターン最大化) | TOP-N固定からリスク制約付ポートフォリオへ拡張 | 施策3の信頼区間情報、マルチタスク出力 |

## 優先施策の詳細

### 1. データ多様化と特徴量拡張（Phase 1）
- **狙い**: 時系列・需給・マクロ因子を追加し、モデルが捕捉できる変動要因を広げる。
- **実施済みタスク**
  1. ✅ 株主信用残データの自動取得・特徴量化（`credit_balance_fetcher.py`）。
  2. ✅ ニュース/決算ヘッドラインのEmbedding化（TF-IDF+SVD）と日次指標作成。
  3. ✅ 高頻度マーケットデータの圧縮。5分足が取得できない場合は日次代理指標でフォールバックし、取得状況をレポート化。
  4. ✅ 特徴量重要度/SHAPレポート生成（`analysis/feature_contribution_report.py`）。
  5. ✅ 外部データ品質サマリーを自動出力（`analysis/external_data_quality_report.py`）。
  6. ✅ 実データのみで再学習・ハイパーパラメータ最適化を実施し、旧モデル比で精度が向上する構成を確定（Accuracy 0.6191 / Precision 0.3035 / Recall 0.4453 / F1 0.3610 / WF平均 0.6397）。
- **残タスク / 運用方針**
  - 公式リアルタイムデータ（JPX Real Time / J-Quants Pro / 日経CP等）の契約可否を法務・企画と調整。
  - チャネル確定後は `HighFreqMarketFeatureBuilder` の取得処理を正式ソースへ切り替える。
  - 取得状況が整い次第、ウォークフォワード再学習でPrecision改善幅を評価。
  - 精度をさらに伸ばすための細分タスク：
    1. [ ] 信用残データ欠損銘柄（例: 65020, 96130）の代替ソース調達・埋め合わせ策を検討。
    2. [ ] ニュースEmbeddingの寄与度を分析し、効果が薄い列を整理（SHAPレポートを活用）。
    3. [ ] 外部指標のA/B評価（含む/除外）を実施し、モデルの当たり率に貢献しない特徴量を削除。
    4. [ ] LightGBMのハイパーパラメータ探索レンジを広げ、Precision重視のチューニングを追加で実施。
    5. [ ] 信用残×ニュース、信用残×マーケットなど複数指標の組み合わせ特徴量を追加し、再評価。
    6. [ ] 高頻度データが正式に取得できた段階で、代理指標と差し替えるための検証プランを作成。
- **完了定義**: 新特徴量を含む再学習でウォークフォワードPrecisionが+2pt以上改善し、リークチェックを通過。（再学習時に改めて検証する）
- **KPI**: Precision@0.60の改善幅、予測陽性率の維持 (>0.3%)。

### 2. モデリング刷新（アンサンブル/深層学習）（Phase 2）
- **狙い**: LightGBM単体の限界を超え、複数モデルの組み合わせで検知力を底上げする。
- **実施済みタスク**
  1. ✅ `systems/close_precision_ensemble_system.py` を新設し、LightGBM・CatBoost・ロジスティック回帰のスタッキングを実装。
  2. ✅ ウォークフォワード互換の時系列CV (n=4, test=42日) とホールドアウト (2025-07-24〜2025-10-24) で性能を評価。
  3. ✅ `tests/test_close_precision_ensemble_system.py` でアンサンブル学習の最小動作を保証。
  4. ✅ `reports/daily_stock_recommendation_close_v1.py` をアンサンブル出力対応に刷新し、運用レポートが自動的に新モデルを参照するよう更新。
  5. ✅ `config/close_recommendation_config.json` を Top3仕様に刷新（確率閾値 0.23、セクター上限 1銘柄）、日次推奨が常に3銘柄出力されるよう調整。
  6. ✅ 流動性×ボラティリティ×モメンタム（3×3×3）の27クラスターでメタモデルを最適化し、Top3的中率を **29.1% → 40.7%** に改善（`systems/close_precision_cluster_optimizer.py`）。
- **検証結果（ウォークフォワード平均 / ホールドアウト）**
  - アンサンブル: Precision 0.308、Recall 0.565、F1 0.398、Accuracy 0.578、Top3 Precision 0.333（CV平均）
  - ホールドアウト (2025-07-24〜2025-10-24): Precision 0.402、Recall 0.011、Accuracy 0.733、F1 0.021、Top3 Precision **0.418**（189推奨 / 日平均3件）
  - クラスタ別メタモデル導入後のホールドアウト: Top3 Precision **0.407**（ベースライン 0.291）。流動性Mid × ボラNeutral × モメンタムMid クラスタが 43%前後で最良。
  - LightGBM単体（ホールドアウト）: Precision 0.389、Top3 Precision 0.386（平均3件）
  - CatBoost単体（ホールドアウト）: Precision 0.342、Top3 Precision 0.423（平均3件）
  - ロジスティック回帰単体（ホールドアウト）: Precision 0.303、Top3 Precision 0.407（平均3件）
  - **要約**: Precision重視のメタモデル最適化＋クラスタ分岐により、Top3的中率が **29.1% → 40.7%** に改善。日次推奨ゼロ日は解消され、平均3件/日の出力を維持したまま命中率を底上げできた。
- **残タスク / 次アクション**
  1. ✅ メタモデル出力の確率キャリブレーション（Isotonic）を導入し、Top3 Precision評価と整合するスケールへ補正。
  2. ✅ Top3/TOP5の命中率・損益分布を更新（`analysis/ensemble_precision_metrics.json`, `analysis/ensemble_holdout_predictions.csv` に記録）。
  3. ✅ 流動性×ボラティリティのクラスタリングを整備し（`analysis/sector_top3_precision_summary.csv`）、コードごとのクラスタ割当を `code_cluster_map` として保存。
  4. 🔄 クラスタ別メタモデルのリファイン（閾値最適化、追加特徴、外れ値除外など）。
  5. [ ] CatBoost・LightGBM のハイパーパラメータをアンサンブル前提で追加最適化し、Top3 Precisionの上積み余地を再検証。
  6. [ ] 簡易MLPなど追加モデルを試験導入し、スタッキング候補を広げる（精度向上が確認できたもののみ採用）。
  7. [ ] 新設定（Top3, 閾値0.23）での月次バックテストと損益検証を実施し、運用指標（勝率・PF）の改善幅を確認。
  8. [ ] セクター情報（33業種等）の取得チャネルを確定し、クラスタを業種要素と組み合わせる。
- **完了定義**: Top3 Precisionが 0.40 以上で安定し、推奨枯渇率 0%、日次平均3件を維持した状態で実装・レポートが自動運用されていること。
- **KPI**: Top3 Precision (>=0.40)、日次平均推奨数 (=3 件)、推奨ゼロ日の比率 0%、Top3損益の月次プラス継続。
