# 追加データ取得調査レポート（信用残・ニュース）

## 概要
- 目的: Precision向上施策（優先度1）に向け、需給指標と外部ニュースのデータソースを調査し、サンプル取得まで完了。
- 実施日: 2025-10-24
- 担当: Automation Agent

## 対象データ
| 種別 | ソース | 取得方法 | 備考 |
| ---- | ------ | -------- | ---- |
| 信用取引残（売残/買残/倍率） | 株探 (https://kabutan.jp) | 公開銘柄ページからHTMLスクレイピング | 日次更新、直近5週分を取得可能。営利利用は利用規約確認が必要。 |
| ビジネスニュース | Yahoo!ニューストピックス（RSS） | https://news.yahoo.co.jp/rss/topics/business.xml | 数分〜数時間ごとに更新。過去分はRSS内のみ。二次利用ポリシーに留意。 |
| 高頻度マーケット指標 | yfinance（^N225, ^TOPX, USDJPY=X, NIY=F） | 5分足データをAPI経由で取得し日次要約 | 直近5日程度の履歴。利用規約・アクセス制限に注意。 |

## 実装とサンプル
- 主要スクリプト: `data_management/update_external_features.py`
  - Kabutan信用残スクレイパ（`credit_balance_fetcher.py`）とYahoo!ニュースRSS取得（`news_headline_fetcher.py`）を連携し、最新データを収集。
  - 信用残は 225 銘柄を対象に 5週間分を取得後、日次補間・5日変化量などの特徴量を生成し `data/external/margin_balances/margin_features_*.parquet` へ保存。
  - ニュースはビジネス/経済/マーケット/テクノロジーRSSを統合し、日次の件数・ソース数・ポジ/ネガキーワードヒット・TF-IDF+SVDによる埋め込み平均などを算出し `data/external/news_headlines/news_features_*.parquet` に蓄積。
  - 5分足マーケット指標は `highfreq_market_feature_builder.py` で日次に圧縮（範囲率、30分リターン、ボラティリティ、出来高比率）し `data/external/highfreq_market/highfreq_features_*.parquet` に保存。Yahoo Financeから取得できない場合は、ローカルの日経平均日次データから代理指標を生成するフォールバックを用意し空列を残さない。
- 初回実行サマリー:
  ```bash
  python data_management/update_external_features.py --log-level INFO
  ```
  - 信用残日次特徴量: 225銘柄 × 当日まで（5週間程度）
  - ニュース日次特徴量: 直近のRSSヘッドラインを日単位に集計

## データ検証メモ
- 信用残日次特徴量列: `margin_buy_balance`, `margin_sell_balance`, `margin_net_balance`, `*_delta_5d`, `margin_long_short_ratio`, `margin_ratio_change_5d` 等。単位は千株。
- 高頻度マーケット特徴量: `hf_nikkei225_close_return`, `hf_nikkei225_last30_return`, `hf_usdjpy_volatility` など各シンボル別に生成。Yahoo側で短期足が配信されない場合は日次データから代理指標を計算し、定期的に正式な高頻度ソースへ差し替える前提。
- Kabutanの日付は月日表記のみのため、実装側で現在年を補完し、月比較で前年へロールオーバー対応。
- RSSレスポンスはUTF-8 XML。`guid`は記事固有IDで重複除去に使用可能。

## 次ステップ案
1. ライセンス・利用規約を精査し、商用利用可否とキャッシュ保持期間を整理する（Kabutan/Yahoo!）。高頻度データは有償ソース（証券会社API等）への切り替えを検討。
2. 信用残データのカバレッジ確認（全日経225銘柄での遅延・欠損率調査）。
3. ニュースはカテゴリ別（マーケット、テクノロジー等）RSSを拡張し、Embeddingモデルの高度化（日本語BERT等）を検討。
4. 高頻度代理指標と実際の5分足データ（入手後）との乖離を検証し、重み付けを最適化。
5. サンプルデータを`notebooks/`で可視化し、既存特徴量との相関やリフトを評価。
