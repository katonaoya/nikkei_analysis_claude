# 閾値探索メモ (2025-10-12 Codex-A)

## 入力データセット
- スクリプト: `analysis/build_multi_model_candidate_dataset.py`
- コマンド: `PYTHONPATH=. python analysis/build_multi_model_candidate_dataset.py --lookback-days 20 --max-candidates 150`
- 収集区間: 2025-09-11〜2025-10-10 (営業日 20 日)
- 件数: 3,000 行 (`analysis_date × code`)
- 特徴: `prediction_probability`, `downside_probability`, `risk_score`, `future_return` (翌日リターン)

## 評価条件
- グリッドサーチ: `analysis/multi_model_threshold_optimizer.py`
  ```bash
  PYTHONPATH=. python analysis/multi_model_threshold_optimizer.py \
    --input production_data/multi_model_candidates.parquet \
    --threshold-up-grid 0.12,0.13,0.14,0.15,0.16 \
    --threshold-down-grid 0.46,0.48,0.50 \
    --risk-grid 0.35,0.40,0.45,0.50,0.55 \
    --weight-up 1.0 --weight-down 0.5 --weight-risk 0.4 \
    --top-n 5 --target-return 0.01 --transaction-cost 0.002 \
    --metric precision --min-valid-count 30 --top-k 20 \
    --export-csv analysis/multi_model_threshold_grid.csv
  ```
- しきい値通過銘柄のみ採用（`require_passed_all=True`）。

## 主な結果（Precision順）
|しきい値 (up / down / risk)|採用銘柄数 (全期間合計)|有効未来リターン件数|Precision|平均リターン|営業日カバレッジ|
|---|---|---|---|---|---|
|0.14 / 0.50 / 0.35|37|35|25.7%|+0.19%|100%|
|0.14 / 0.50 / 0.40|39|37|24.3%|+0.04%|100%|
|0.14 / 0.50 / 0.45|40|38|23.7%|-0.01%|100%|

> 備考: `avg_return` は未来リターン平均、`coverage_rate` は上記20営業日に対して推奨が出た日の割合。

## 推奨値の採用理由
- 閾値を `(up=0.15, down=0.48, risk=0.50)` に設定すると、各営業日で 2〜3 銘柄の推奨が出現し、直感的に許容できる保守性が確保された。
- 上記設定での検証（`PYTHONPATH=. python reports/daily_stock_recommendation_multi.py --date 2025-10-10`）では推奨 2 件を確認。
