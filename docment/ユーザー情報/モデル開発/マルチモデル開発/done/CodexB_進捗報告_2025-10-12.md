- ロードマップのフェーズ2「推論統合としきい値探索」に沿って、終値モデル出力を全候補で再利用できる `DailyStockRecommendationCloseV1.predict_all_candidates` を整備。
- `reports/daily_stock_recommendation_multi.py` を新設し、`P_up`, `P_down`, `Risk_score` の閾値フィルタと線形結合スコアを設定ファイル駆動で実装。欠損時はデフォルト値にフォールバック。
- `config/multi_model_recommendation.json` を整備し、しきい値・重みを外部化（現行値: `threshold_up=0.14`, `threshold_down=0.50`, `threshold_risk=0.35`, `weights=(1.0,0.5,0.4)`)。Codex-A が生成する下落/リスク予測ファイルの入力パスもここで管理。
- `daily_trading_automation.py` にマルチモデルレポート生成ステップを追加し、日次パイプラインで Close→マルチモデルの連携が自動で走るように更新。
- `tests/reports/test_multi_model_recommendation.py` を追加し、フィルタ判定とフォールバック処理、欠損時のデフォルト適用をユニットテストでカバー。
- 終値モデルとマルチモデル共通で利用できるスコアリング関数 `prepare_candidate_scores` / `select_top_candidates` を整備し、レポート・評価スクリプト双方から再利用可能にした。
- `analysis/build_multi_model_candidates.py` を追加し、終値/下落/リスク出力を統合した候補データセットを生成できるようにした（`analysis/build_multi_model_candidate_dataset.py` と併用し、最新20営業日・計3,000件の `production_data/multi_model_candidates.parquet` を構築）。
- `analysis/multi_model_threshold_optimizer.py` を追加し、閾値 (`threshold_up/down/risk`) グリッドサーチ、Precision/リターン指標算出、設定ファイル更新までを一括実行可能にした。`--metric-weights` で Precision / AvgNetReturn / Coverage の重み付きソートに対応。
- `analysis/multi_model_precision_report.py` を追加し、設定ファイルを使った Precision / 平均リターン / Coverage のサマリ出力を CLI から即時確認可能にした。
- 上記データセットで `analysis/multi_model_threshold_optimizer.py ... --metric-weights precision:0.5,avg_net_return:0.3,coverage_rate:0.2` を実行し、Precision 41.46%・平均リターン +0.59%・Coverage 55%（`threshold_up=0.18`, `threshold_down=0.50`, `threshold_risk=0.40`、重み = 1.0/0.5/0.4）を採用。`config/multi_model_recommendation.json` を同値に更新し、フォールバック許容量 (`fallback.max_fallback`) を設定で調整可能にした（デフォルトは0でフォールバック無効）。
- `analysis/multi_model_precision_report.py` を追加し、候補データから Precision / AvgReturn / Coverage を迅速に確認できるようにした（例: `PYTHONPATH=. python analysis/multi_model_precision_report.py --input production_data/multi_model_candidates.parquet`）。
- Precision レポート／閾値サーチともに `--fallback-max` / `--fallback-min-passed` 等のオプションを追加し、フォールバック有無のシミュレーションを CLI から即時実行できるように拡張。
- 120 営業日データに対するフォールバック検証では、`fallback_max=1, min_passed_ratio=0.45` でも Precision 33.7% / Coverage 100% に留まり、Precision ≥45%・Coverage ≥60% の同時達成が困難であることを確認。
- `production_data/multi_model_candidates_history.parquet` を再生成（2025-09-11〜2025-10-10 の 3,000 件、未来リターン含む）し、継続的な閾値検証に利用可能な状態に維持。
- `reports/daily_stock_recommendation_multi.py` のレポートテンプレートを拡張し、候補全体・推奨銘柄の平均上昇確率/下落確率/リスク/統合スコア/未来リターンを「📊 指標サマリ」セクションとして出力。
- `tests/analysis/test_multi_model_threshold_optimizer.py` を追加し、閾値評価ロジックと候補データ読込ユーティリティをカバー。

## 補足・前提
